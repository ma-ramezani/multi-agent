مسئله

۰۲سفارش چه بود — و ما چه فهمیدیم؟

پیام کارفرما کوتاه و کلی بود: «با Neuron یک پروژه‌ی لاراول بساز…» — ما آن را به ۶ قابلیت قابل تحویل و قابل تست ترجمه کردیم:

  • چت زنده با ایجنت + آپلود فایل داخل چت نیاز اصلی
  • تعریف ایجنت‌های مختلف که همه‌ی تنظیمات از وب انجام شود (پرووایدر، مدل، لحن، دما…)
  • محیط RAG — هر ایجنت به چند محیط وصل شود + انتخاب ابزارها برای هر ایجنت
  • API ساده با توکن، برای نرم‌افزارهای دیگر قابل اتصال
درس مدرس: پروژه‌های واقعی با جمله‌ی مبهم شروع می‌شوند. هنر تو، تبدیل ابهام به چک‌لیست قابل آزمون است — قبل از نوشتن حتی یک خط کد.
تصمیم معماری

۰۳با چه چیزی ساختیم — و چرا همین‌ها؟

Laravel 12

صف (queue)، سشن و کش روی دیتابیس، اعتبارسنجی و Eloquent — تا به‌جای اختراع چرخ، روی منطق ایجنت تمرکز کنیم. SQLite کافی بود؛ بدون نیاز به MySQL/Redis.

Neuron AI 4

انتزاع Agent، RAG، Provider، Tool و استریم SSE — موتور استدلال پروژه. یک API برای ده پرووایدر.

Ollama + nomic-embed-text

امبدینگ لوکال، رایگان و آفلاین روی همان سرور. دانش داخلی هرگز به بیرون نمی‌رود و هزینه‌ی امبدینگ صفر است.

Tesseract + Poppler + faster-whisper

OCR فارسی/انگلیسی برای اسکن‌ها، pdftoppm برای PDF، و large-v3-turbo برای رونویسی ویس — دنیای واقعی پر از فایل اسکن‌شده و ویس‌نوت است.

کارهای سنگین

۰۶چرا صف پس‌زمینه؟

  • OCR یک کتاب ۸۲ صفحه‌ای ≈ ۲۵ دقیقه — هیچ رکوئست وبی نباید این‌قدر باز بماند.
  • قانون پروژه: PDF و فایل بالای ۳ مگ → صف (IngestRagDocument)، بقیه فوری. تشخیص خودکار
  • ورکر دائمی با supervisord (داکر) و systemd (هاست) + صفحه‌ی سند با دیدن processing خودکار رفرش می‌شود.
درس: «کار سنگین» را از روز اول جدا کن — نه وقتی که سرور قفل کرد. و هرگز حین اجرای job، ورکر را kill نکن؛ ساعت‌ها زمان دور می‌ریزد.
موتور چت — ارزان و رایگان

۰۷چت با OpenCode Go — بدون هزینه‌ی اضافی

  • یک پرووایدر سازگار با OpenAI به آدرس opencode.ai/inference/go/openai/v1 — با هدرهای User-Agent و x-opencode-session برای مسیریابی و کش پرامپت.
  • تحمل استریم‌های بدون finish_reason: اگر متنی آمده، پاسخ کامل برگردانده می‌شود (رفع خطای معروف استریم).
  • در فرم ایجنت کافی است پرووایدر را OpenCode Go و مدل را مثلاً longcat-2.5-preview-free بگذاری — فقط کلید را در .env بگذار.
برای شروع رایگان: یک کلید OpenCode Go بگیر، همین پروژه را با docker compose up بیار بالا — بدون پرداخت به OpenAI هم چت کار می‌کند.
تجربه‌ی کاربری

۰۸چت زنده — متن، فایل و صدا

استریم SSE

پاسخ تکه‌تکه می‌آید؛ با EventSource بدون نیاز به وب‌سوکت. روی هر مرورگری کار می‌کند.

پیوست چندفایل

ورد/اکسل/پاورپوینت/PDF/عکس/صوت — درگ‌دراپ روی کادر چت، پیش‌نمایش وضعیت خوانش، و تزریق متن به پرامپت.

صدا

میکروفون با Web Speech API (fa-IR) + فایل صوتی با پخش‌کننده و رونویسی خودکار فارسی.

رابط کاملاً فارسی، فونت وزیرمتنِ لوکال (بدون وابستگی به اینترنت) و آیکن‌های استاندارد SVG — بدون ایموجی.

امنیت — پنج لایه

۰۹چگونه امن ماندیم؟

لایهچه می‌کند
سپر پرامپت ضداینجکشنبلوک متنی به انتهای همه‌ی ایجنت‌ها الحاق می‌شود؛ از فرم قابل حذف نیست.
سندباکس فایلتولکیت خام (bash/delete) حذف و با ScopedFileTool فقط-خواندنی در agent-files جایگزین شد.
دیتابیسفقط SELECT + لیست سیاه جداول و ستون‌های حساس + ممنوعیت چنددستوری.
SSRFآدرس‌های داخلی، شبکه خصوصی و متادیتای ابری حتی در ریدایرکت‌ها بسته می‌شوند.
فیلتر خروجیSafetyFilter الگوهای sk-/ak-/Bearer و مقادیر کلیدها را قبل از ذخیره پاک می‌کند.

همه در مرکز امنیت (/security) قابل مشاهده و تنظیم‌اند — ۱۴ گزینه بدون دست‌کاری کد، به‌همراه ممیزی کامل رویدادها.

۱۱متن فارسی آینه‌ای! بحرانی‌ترین

  • خروجی OCR بود: دنک ظفحدنک حلاصا — کل کتاب ناخوانا! فاجعه‌ی خاموش
  • ماتریس تست روی یک صفحه: fas+eng جهت را LTR حدس می‌زد، fas تنها درست بود → زبان اول، جهت پاراگراف را تعیین می‌کند.
